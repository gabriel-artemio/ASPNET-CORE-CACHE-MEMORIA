<h1>DotLab Exames API : Monitoramento de Exames Laboratoriais</h1>

API que gerencia pedidos e resultados de exames.

<h3>Funcionalidades:</h3>

<ul>
  <li>CRUD de exames e laudos.</li>
  <li>Associação de exame a paciente e médico solicitante.</li>
  <li>Upload de resultados (ex: PDF simulado).</li>
  <li>Autenticação JWT com diferentes permissões (laboratório, médico, paciente).</li>
  <li>Sistema de notificação (ex: envio de e-mail simulando alerta quando resultado fica pronto).</li>
  <li>Histórico de exames do paciente.</li>
</ul>
